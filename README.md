# Xilinx Vivado exercises

Some exercises I carried out in the [Xilinx Vivado](https://www.amd.com/en/products/software/adaptive-socs-and-fpgas/vivado.html) (now AMD i guess) suite of programs for digital logic design and simulation.
The raw VHDL code should run fine on [GHDL](https://github.com/ghdl/ghdl) and viz fine on [GTKWave](https://gtkwave.sourceforge.net/).
